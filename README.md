# IntegriQ IT (Portfolio)

#### [Frontend Live Link]()

## Features

- **Header** – Responsive navigation with mobile menu
- **Hero** – Compelling headline with statistics and CTA buttons
- **Services** – 6 core fintech services with hover effects
- **Features** – Key platform benefits with badges
- **Techonology** – Detailed description of our tech stack
- **About** – Company story with impressive stats
- **Contact** – Contact form and information
- **Footer** – Links and social media

## Technology Stack

- **Programming Language:** TypeScript
- **Web Library & Utilities:**
  - `react`, `react-dom`, `react-router-dom`
  - `clsx`, `tailwind-merge`, `class-variance-authority`
  - `@radix-ui/react-separator`, `@radix-ui/react-slot`
  - `lucide-react`
- **Styling:** Tailwind CSS
- **State Management:** Context API

## Project Setup Instructions

1. Clone the repository:

   ```bash
   git clone your_git_repo_url
   ```

2. Install dependencies:
   ```bash
   yarn install # or npm install
   ```
3. Run the development server:
   ```bash
   yarn dev # or npm run dev
   ```
4. Open `http://localhost:5173` in your browser.
